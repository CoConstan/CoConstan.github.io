<h2>Some videos for theoretical background:</h2>
<figure class="post__video"><iframe width="560" height="314" src="https://www.youtube.com/embed/FBpPjjhJGhk" allowfullscreen="allowfullscreen" data-mce-fragment="1"></iframe></figure>
<p>You can start by watching <a href="https://youtu.be/FBpPjjhJGhk" target="_blank" rel="noopener noreferrer">But what is a neural network REALLY?</a> by Algorithmic Simplicity. To go further, the entire <a href="https://www.youtube.com/playlist?list=PLZHQObOWTQDNU6R1_67000Dx_ZCJB-3pi" target="_blank" rel="noopener noreferrer">3Blue1Brown neural networks playlist</a> is a great starting point. Once you have finished that playlist, you can return to <a href="https://www.youtube.com/@algorithmicsimplicity" target="_blank" rel="noopener noreferrer">Algorithmic Simplicity's channel</a> and look for videos about specific models.</p>
<p>The first two channels focus heavily on mathematics, so if you are looking for a perspective more closely aligned with computer science, consider watching Sebastian Lague's video: <a href="https://www.youtube.com/watch?v=hfMk-kjRv4c">How to Create a Neural Network (and Train it to Identify Doodles)</a>.</p>
<p>Before jumping into PyTorch and TensorFlow, try building your own neural network from scratch to check that you fully understand the basics of backpropagation and neural networks.</p>
